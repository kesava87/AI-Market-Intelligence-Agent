# 📌 Overview

AI Market Intelligence Agent is an AI-powered automation platform that continuously collects AI news articles and GitHub repositories, generates intelligent summaries using Ollama LLMs, performs market trend analysis, builds an interactive HTML dashboard, and automatically emails executive reports.

This project demonstrates practical applications of Artificial Intelligence, Large Language Models (LLMs), Automation, Natural Language Processing (NLP), Data Engineering, Trend Analysis, and Executive Reporting in a real-world workflow.

---

# ✨ Key Features

- 📰 Real-time AI News Collection
- 💻 Trending GitHub Repository Tracking
- 🤖 AI-powered Summarization using Ollama
- 📊 AI Market Trend Analysis
- 📈 Interactive HTML Dashboard

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/kesava87/AI-Market-Intelligence-Agent.git
```

---

## Navigate to Project

```bash
cd AI-Market-Intelligence-Agent
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Configure

Update the configuration values inside:

```text
config.py
```

---

## Run

```bash
python main.py
```
